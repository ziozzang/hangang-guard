동적 규칙 · Lua 
검증은 서버 정책을 바꾸지 않습니다. 저장한 규칙은 다음 요청 결정에 적용되며, 별도로 켜 둔 짧은 캐시는 만료까지 이전 결정을 사용할 수 있습니다.
불러오기를 누르면 JSON 초안을 교체합니다. Lua 초안은 유지합니다.
JSON 규칙
각 규칙은 id, priority, network, countries, asns, action, score, expires_at, description을 사용합니다. action은 observe / allow / deny입니다. network·countries·asns 조건은 함께 평가하며, 우선순위가 높은 규칙의 결정이 먼저 적용됩니다.
Lua 규칙
Lua 스크립트는 { version = 1, rules = { … } } 테이블을 반환합니다. 검증된 결과를 JSON 규칙으로 저장하며, Lua 소스 초안은 현재 페이지에 유지합니다.
